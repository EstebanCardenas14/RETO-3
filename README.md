# RETO-3
RETO 3 > PERIFERIA: MVP web para automatizar la creación de órdenes de compra en SAP simulado. Procesa solicitudes, cotizaciones, aprobaciones y facturas; valida reglas de negocio RC1–RC10, detecta bloqueos y excepciones, solicita confirmación humana cuando corresponde y genera evidencia, trazabilidad e idempotencia de las OCs creadas.
